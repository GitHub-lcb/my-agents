## 约定

- 每个分析产物独立成目录，放在 `docs/<主题>/` 下，自带 `README.md` 说明结构、结论与复现方式。
- 分线原始材料放在该目录的 `appendix/`，机器可读数据放在 `tokens/`（或同类数据目录）。
- 报告中标注证据等级：**实测** / **推断** / **未确认**，不臆测产物中不存在的规范。
